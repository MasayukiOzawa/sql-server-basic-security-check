# システム管理者権限が付与されているログイン

- 目的: `sysadmin` 固定サーバーロールに所属するログインを一覧化する。付与の妥当性は自動判定せず「情報」とする。
- 対象: `sys.server_role_members` と `sys.server_principals`。直接所属とサーバーロール経由の所属をたどる。無効ログイン、Windows／Entra グループ、証明書等のログインも除外しない。経由ロールはログインと区別して表示する。
- 必要権限: 各カタログの参照権限とメタデータの可視性。全ロール所属の参照には VIEW ANY DEFINITION または securityadmin 等が必要。個別のログインやロールの非表示にも注意し、権限は自動付与しない。
- SQL: [check-sysadmin-logins.sql](../assets/queries/check-sysadmin-logins.sql)。再帰で付与経路を取得し、同一経路内の循環を除外する。複数経路を持つログインは経路ごとに出力し、ログイン数は ID で重複を除く。
- 判定: 一覧は「情報」。sysadmin ロールが取得できない、全所属の参照権限が確認できない、メンバー詳細が非表示の場合は「未判定（可視範囲のみ）」。0 件を安全・正常・管理者不在と断定しない。接続・SQL エラーや再帰上限到達は未判定。
- 出力: 取得ログイン数、可視性確認、全メンバーの ID・名前・種類・is_disabled／有効状態・直接の付与元ロール・階層の深さ・経路の ID 列・注記。経路 ID は一覧の principal_id と対応付けて説明する。件数のみの報告や行の省略はしない。
- 限界: Windows／Entra グループの内部メンバーは展開しない。SQL Server に直接登録されていないユーザーもグループ経由で権限を持ち得る。非表示の所属・ログインは未確認。CONTROL SERVER、偽装、権限昇格経路などを含む実効権限の網羅調査ではない。ログインの有効状態は接続可否の保証ではなく、ロール行には適用しない。
- 実行: [一括入口](../scripts/Invoke-SecurityChecks.ps1) の既定項目に含む。単独では `-Checks 'sysadmin logins'`。ログイン試行、グループ照会、権限の付与・剥奪、設定変更は行わない。

## 結果報告のひな形

- 実行状況／接続先／取得ログイン数／可視性:
全メンバーを次の列見出し付き表で掲載する。

| principal_id | 名前 | 種類 | is_disabled | 有効状態（ロールは対象外） | 付与元ロール | parent_role_id | 深さ | 経路 ID | 注記 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |

- 判定と根拠: 情報または未判定。sysadmin からの所属経路。
- 未確認事項: 非表示メタデータ、グループ内ユーザー、個別付与の CONTROL SERVER 等。
- 権限・設定変更: なし。

仕様: [Microsoft Learn: sys.server_role_members](https://learn.microsoft.com/sql/relational-databases/system-catalog-views/sys-server-role-members-transact-sql)。

## 表形式での出力必須

Markdown／HTML の表で全所属経路の全行を出力する。プレーンテキストやコードブロックだけで代用しない。複数経路は統合せず、ユニークなログイン数と表の行数を区別する。経路 ID は principal_id と対応付け、無効ログイン・グループ・経由ロール・未取得値を省略しない。0行の場合も列見出しと0件を示し、取得失敗は0件とせず未判定の理由を記載する。保存後に全10列・行数・取得値と元結果を照合する。
