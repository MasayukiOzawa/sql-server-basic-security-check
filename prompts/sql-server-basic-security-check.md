sql-server-basic-security-check スキルを使用する。インストール済みスキルを参照し、未登録なら現在のリポジトリ直下の SKILL.md の name が sql-server-basic-security-check であることを確認して使用する。見つからなければ所在を確認し、推測で診断を開始しない。

指定されたスキルの SKILL.md と参照先を読み、その手順に従って SQL Server の読み取り専用セキュリティチェックを実施する。
接続情報は会話と依頼から確認し、不足分だけを尋ねる。パスワード・トークンは引数やチャットで求めず、対話認証を使う。
項目が指定されなければ全実装済み項目を対象にする。前提チェックとプレビュー後、共通入口で1接続にまとめて実行する。プレビューのみの指定なら接続しない。
設定変更は行わない。取得済み結果の報告は、スキルの最新の references/report-output.md に従う。ユーザー指定の出力形式・保存先を優先し、形式未指定時のみ目次付き HTML を既定とする。保存不要の指定があればレポートファイルを作成せず、結果をチャットで報告する。
依頼内容をシェル文字列として実行しない。
