# リンクサーバーの設定状況

- 目的: ローカルに定義されたリンクサーバーとログインマッピングを一覧化する。設定の適否を独自に正常／異常判定しない。
- 対象: `sys.servers` の `server_id <> 0 AND is_linked = 1`、対応する `sys.linked_logins` とローカルログイン名の参照。ローカルサーバーと旧式のリモートサーバー定義は対象外。
- SQL: [check-linked-servers.sql](../assets/queries/check-linked-servers.sql)。選択名は `linked servers`。既定の一括チェックに含む。
- 出力: サーバー ID・名前、製品、プロバイダー、データソース、既定カタログ、Data Access、RPC（is_remote_login_enabled）、RPC Out、リモートプロシージャのトランザクション昇格、照合順序互換・リモート照合順序の使用・照合順序名、遅延スキーマ検証、接続／クエリタイムアウト、変更日時の全行。
- マッピング出力: サーバー ID・名前、ローカル principal_id・ログイン名、uses_self_credential、リモートログイン名、変更日時、認証方式の説明。local_principal_id = 0 は個別指定のないログインへの既定マッピング。名前が非表示でも行を落とさない。自己資格情報を使わず remote_name が NULL の場合と、マッピング行自体がない場合を区別する。
- 必要権限: ローカルカタログの参照とメタデータの可視性。全サーバーの可視性の指標として ALTER ANY LINKED SERVER、ALTER ANY LOGIN、setupadmin／sysadmin を確認する。環境によって VIEW SERVER SECURITY STATE 等も必要。権限付与やバージョンによる実行禁止は行わない。
- 判定: 取得結果は「情報」。取得失敗、全サーバー可視性を確認できない場合、マッピングのローカルログイン名が取得不能の場合は「未判定（取得範囲を参照）」。サーバー設定とマッピングは独立して取得し、一方が失敗しても取得できた結果を出す。
- 0 件の扱い: 可視性不足で「リンクサーバーなし」と断定しない。マッピングは別途可視性が制限され得るため、0 件は「参照できたマッピング0件」と記す。権限指標だけで全マッピング取得を保証しない。NULL の設定値も推測しない。
- 秘密情報: パスワードや資格情報、秘密情報を含み得る provider_string は取得・出力しない。取得した名称やデータソースに秘密情報が混入している場合はレポート出力手順に従って伏せ字にする。
- 境界: OPENQUERY、OPENROWSET、4部名、EXEC AT、sp_testlinkedserver 等によるリモート参照・接続テストは行わない。設定・マッピングの作成変更削除、権限付与も行わない。プロバイダー文字列を取得しないため暗号化等の接続オプション、資格情報の有効性、委任、リンク先の権限は未確認。

## 表形式での出力（必須）

チャットとレポートの両方で、Markdown テーブルまたは HTML の table 要素を使用し、列見出し付きの表で全対象行を掲載する。sqlcmd のプレーンテキストやコードブロックだけで代用しない。件数制限・省略記号で行を省かない。

名称内の空白、NULL、空文字を区別し、表の区切り文字・改行は適切にエスケープする。単純な空白分割で曖昧な列を推測しない。列を確定できない場合は未判定の理由を表に明記する。0件と取得不能を区別し、架空の詳細行は作らない。保存後に取得件数・掲載行数・各列の値を照合する。

リンクサーバー設定とログインマッピングは別々の表とする。

- 設定表は「出力」に挙げた全設定列を保持する。列数が多い場合は接続先・接続オプション・照合順序等に分割してよいが、各表にサーバー ID と名前を付け、同じサーバーを照合できるようにする。列を省略しない。
- マッピング表は、サーバー ID・名前、ローカル principal_id・ログイン名、uses_self_credential、リモートログイン名、変更日時、認証方式の説明を列にする。1マッピングにつき1行とし、既定マッピングと個別マッピングを区別する。
- 可視性・判定・エラーと未確認事項も表の前後に明記する。原文を補足資料として保存しても、本文の表は必須。

## 結果報告のひな形

- 実行状況／接続先／実行日時:
- 参照できたサーバー数・マッピング数／可視性／判定・取得エラー:
- サーバー設定表: 上記の全設定列・全行。
- ログインマッピング表: 上記の全列・全行。
- 未確認事項: 非表示設定、マッピング、リンク先への接続・権限、秘密情報を含む接続オプション。
- リモート接続・設定変更: なし。
