# 直近7日間で変更された SQL Server エージェントジョブ

- 目的: 最近変更されたジョブを情報として列挙する。変更の有無を正常／異常と判定しない。
- 対象: 接続先インスタンスの `msdb.dbo.sysjobs`。有効・無効の両方のジョブを対象にする。ジョブは msdb で管理されるため、各ユーザー DB を巡回しない。
- 期間: SQL Server のローカル日時 `SYSDATETIME()` をチェック開始時に固定し、7日前以上・開始時刻以下の `date_modified` を抽出する。新規作成されたジョブも、この期間に該当すれば含める。
- 必要権限: msdb にアクセスでき、`msdb.dbo.sysjobs` の対象列を SELECT できること。Agent のロール所属だけで直接 SELECT の成功を保証せず、実行結果を確認する。権限の自動付与や認証方式の変更は行わない。
- SQL: [check-recent-agent-job-changes.sql](../assets/queries/check-recent-agent-job-changes.sql)。読み取り結果をセッション内の表変数に保持し、件数と詳細の整合を保つ。
- 判定基準: 対象が1件以上なら「検出あり」、取得成功で0件なら「検出なし」。取得失敗、msdb にアクセス不可、機能やテーブルが存在しない場合は理由付きで「未判定」。date_modified が NULL の行も未判定として列挙し、全体を未判定にする。
- 出力: 対象期間（サーバーローカル時刻）、取得ジョブ数、検出件数、ジョブ ID・名前・有効状態（enabled: 1=有効、0=無効）・作成日時・変更日時を含む全行。件数や一部の行だけで済ませない。
- 限界: 最終変更日時の一覧であり監査履歴ではない。変更者・変更内容・削除済みジョブ・実行履歴は取得しない。スケジュール等の関連情報だけの変更で sysjobs.date_modified に反映されないものは検出対象外。ジョブステップのコマンド本文は取得しない。
- 実行: [一括入口](../scripts/Invoke-SecurityChecks.ps1) の既定項目に含む。単独では `-Checks 'recent agent job changes'`。同じ接続で実行し、別の認証は行わない。ジョブの起動・停止・変更および設定変更は行わない。

## 表形式での出力（必須）

チャットとレポートの両方で、Markdown テーブルまたは HTML の table 要素を使用し、列見出し付きの表で全対象行を掲載する。sqlcmd のプレーンテキストやコードブロックだけで代用しない。件数制限・省略記号で行を省かない。

名称内の空白、NULL、空文字を区別し、表の区切り文字・改行は適切にエスケープする。単純な空白分割で曖昧な列を推測しない。列を確定できない場合は未判定の理由を表に明記する。0件と取得不能を区別し、架空の詳細行は作らない。保存後に取得件数・掲載行数・各列の値を照合する。

変更ジョブ一覧はジョブ ID・ジョブ名・有効状態（enabled の値と説明）・作成日時・変更日時・判定の表とし、1ジョブにつき1行で出力する。日時不明の未判定行も省略しない。対象期間・取得ジョブ数・検出件数・未確認事項は表の前後に記載する。検出件数と日時不明の行数を分けて照合する。
